# Kenney Castle Kit

Downloaded from https://kenney-assets.itch.io/castle-kit on 2026-11-08. License: CC0; original license included.

Models/ contains the original GLB models and their texture companion folder. Textures/ contains the alternate color palettes. Previews/ contains the original pack overview images. Source/kenney_castle-kit.zip preserves the complete original download, including FBX, OBJ and per-model previews.

Assets are staged for future map building; the active citadel has not been replaced. ZIP CRC checks and GLB header/length checks passed. Engine import and rendering have not been tested.
